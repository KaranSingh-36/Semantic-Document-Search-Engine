Natural language processing (NLP) enables computers to read, interpret and generate human language. Typical NLP tasks include tokenisation, part-of-speech tagging, named entity recognition, sentiment analysis, machine translation and question answering. Classical NLP systems used bag-of-words features and statistical models, whereas current systems use transformer neural networks that learn contextual word representations. Search engines use NLP to understand what a user is looking for even when the query is phrased in everyday language.
